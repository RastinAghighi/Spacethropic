# Spacethropic

NASA hackathon team repo.

## Layout

| Folder      | What                                   |
|-------------|----------------------------------------|
| `frontend/` | Next.js app (TypeScript, Tailwind, App Router) |
| `experiments/global_filter/global_r7/` | Resumable r7 filter, regional observations and contour demo; global run awaits MODIS. [Run report](experiments/global_filter/global_r7/RUN_REPORT.md) |

## Frontend

```bash
cd frontend
npm install
npm run dev   # http://localhost:3000
```
